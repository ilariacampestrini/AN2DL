# Artificial Neural Networks and Deep Learning — Politecnico di Milano

Projects developed for the course *Artificial Neural Networks and Deep Learning* (054307), Politecnico di Milano, A.Y. 2024/2025, Prof. Giacomo Boracchi.

## Homework 1 — Image Classification
Multi-class classification of blood cell images (8 classes, 13,759 samples).

**Result:** 98.22% validation accuracy · 86% Codabench accuracy

- [`H1Model.ipynb`](./H1Model.ipynb) — full implementation
- [`H1Report.pdf`](./H1Report.pdf) — written report

## Homework 2 — Image Segmentation
Semantic segmentation of Mars surface images into 5 terrain classes (2,615 training
samples with severe class imbalance). 

**Result:** 70.633 Kaggle score

- [`H2Model.ipynb`](./H2Model.ipynb) — full implementation
- [`H2Report.pdf`](./H2Report.pdf) — written report
